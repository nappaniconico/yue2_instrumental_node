# YuE2 Instrumental ABC

YuE2が生成したABCをインスト用に変換するComfyUIカスタムノードです。V1（Vocalの休符化）とV2（空いているIns小節への旋律移植）を実装しています。追加パッケージやモデルは不要です。

## V2: YuE2 Instrumentalize ABC

ComfyUIを再起動し、検索から **YuE2 Instrumentalize ABC**（`YuE2/ABC`）を追加します。

```text
ABC生成 → YuE2 Instrumentalize ABC → 音声生成
```

V2には**元のABC**を接続してください。V1の後ろに接続すると、Vocal旋律がすでに消えているため移植できません。

小節ごとに次の処理を行います。

1. Insが全休符でVocalに音符があれば、Vocal旋律をInsへコピーします。
2. Insに1音でも音符があれば、その小節のIns全体を保持します。
3. Vocal音符を元の音価の休符へ変換します。コード記号は元のVocalの位置に残します。

`Z` / `Z2` / `Z3` などの複数小節休符と、`z4z4` など休符だけの通常小節に対応します。必要な場合だけ複数小節休符を展開します。

### V2の例

入力:

```abc
M:4/4
L:1/8
K:C
V: Vocal
"C"C4E4|"G"G8|
V: Ins
Z|d8|
```

出力:

```abc
M:4/4
L:1/8
K:C
V: Vocal
"C"z4z4|"G"z8|
V: Ins
=C4=E4|d8|
```

コピーする音符には臨時記号（自然音の `=` を含む）を明示し、元の調・臨時記号・小節をまたぐタイから決まる音程を保持します。移植した音符同士のタイは保持し、移植しない小節へ延びるタイは除去します。

| 出力 | 内容 |
| --- | --- |
| `abc` | 変換後のABC文字列 |
| `muted_notes` | Vocalで休符化した音符トークン数 |
| `moved_bars` | Vocal旋律をInsへコピーした小節数 |
| `report` | 移植小節数・既存Insを優先した小節数などの要約 |

### V2の対応範囲

- `M:`、`L:`、`K:` が明記された、単一曲の単旋律ABCが対象です。voice IDは `Vocal` と `Ins` を使用します。
- 両voiceの小節数、各小節の長さ・単位音価・調・インライン転調位置が一致することを検証します。小節末の `|` が必要です。
- 長調・短調、通常音符・休符、分数音価、タイ、複数小節休符、`[K:...]` 転調、改行をまたぐ小節に対応します。
- 連符・装飾・同時発音・反復記号・インラインvoice切替・歌詞 `w:`・Ins内のコード注釈などはV2の対象外です。対応外の構文や長さ不一致は、行番号などを含むエラーで知らせます。自動でV1へ切り替えません。
- 弱起などの不完全小節には対応していません。変換後にも小節長・調・タイを検証します。
- 元のコメント・ヘッダー・小節線を保持します。Insの移植部分の音符表記と空白位置は元と異なる場合があります。

V1で実行できるABCでも、V2の厳密な小節検証では対象外になる場合があります。

## V1: YuE2 Mute Vocal ABC

1. このフォルダーを `ComfyUI/custom_nodes/yue2_instrumental` に配置します（現在の配置で完了）。
2. ComfyUIを再起動します。
3. ノード検索で **YuE2 Mute Vocal ABC** を追加します。カテゴリは `YuE2/ABC` です。
4. ABC生成ノードの文字列出力 → 本ノードの `abc` 入力 → 音声生成ノードのABC文字列入力、と接続します。ABCを直接貼り付けることもできます。

出力は `abc`（変換後の文字列）と `muted_notes`（置き換えた音符トークン数）です。タイでつながれた音符はトークンごとに数えます。0なら対象音符がないため、入力に `V: Vocal` があるか確認してください。元の入力文字列は変更しません。

## 変換内容

```abc
V: Vocal
"Bbmaj7"z2f2f2c2"C"g3a3g2-|
V: Ins
Z|
```

↓

```abc
V: Vocal
"Bbmaj7"z2z2z2z2"C"z3z3z2|
V: Ins
Z|
```

- 音価・コード記号の位置・小節線・ヘッダー・セクションコメント・改行を保持します。
- `Vocal` のタイを除去します。`Ins` とその他のvoiceの音符は保持します。
- 臨時記号、オクターブ、分数音価、インラインのvoice/key指定に対応します。
- YuE2の単旋律ABCが対象です。Vocalの装飾音 `{...}` や同時発音 `[CEG]` は、音価の誤変換を防ぐためエラーにします。汎用ABCバリデーターではありません。
- 歌詞フィールドや外部の歌詞入力は変更しません。音声生成側の歌詞・スタイルもインスト用途に合わせてください。

V1ではInsが全休符なら主旋律は消えます。旋律を残す場合はV2を使用してください。同じABC・シードで変換前後を比較して、歌声が抑制されるか確認してください。どちらのノードも、生成音声に歌声が出ないことや特定の楽器になることは保証できません。

構想中のV2例にある `z16` へのまとめ直しは行いません。元の音価をそのまま残して、コードの開始位置がずれないようにしています。

仕様参考: [YuE2公式ABC編集ガイド](https://github.com/multimodal-art-projection/YuE/blob/main/skills/yue2-music/references/abc-editing.md)
